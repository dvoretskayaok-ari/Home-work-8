# Semantic Webpage with Navigation and Cards

## Project Goal
To create a structured, accessible, and responsive webpage.

## Technologies and Approaches Used:
- **HTML5 Semantics:** Use of semantic tags. 
- **BEM Methodology:** Logical class naming for easier maintenance and style scalability.
- **Flexbox:** Used for navigation and cards.
- **Fonts and CSS Variables:** Local font integration and centralized color palette management.

## Layout Verification
The layout has been verified in the browser. The navigation menu is built using Flexbox with alignment managed via the `gap` property; cards are arranged using Flexbox; component styles follow the BEM methodology; and there is no horizontal scrolling on the page.
